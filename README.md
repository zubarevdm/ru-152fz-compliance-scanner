# 152-проверка — сканер и генератор документов по 152-ФЗ

MVP-продукт для малого бизнеса: проверить сайт на нарушения 152-ФЗ за 60 секунд
и собрать пакет документов, чтобы закрыть их за вечер — без юриста и аудита.

## Что внутри (сквозной поток)

```
Лендинг (/)  →  Сканер (/scan)  →  Отчёт со штрафами  →  Визард (/documents)
                                                              ↓
                              Оплата (заглушка) → выгрузка DOCX → Подписка-мониторинг
```

- **Tier 0 — Скан (бесплатно).** `/api/scan`: загружает сайт, парсит `cheerio`,
  гоняет 7 детекторов, возвращает нарушения с привязкой к статьям КоАП и суммам штрафов.
- **Tier 1 — Пакет документов (7 900 ₽).** `/api/generate`: визард → DOCX
  (политика, согласие, данные для РКН, приказ) под конкретный бизнес.
- **Tier 2 — Мониторинг (1 990 ₽/мес).** `/api/monitor`: stub для крон-рескана и алертов.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
# или
npm run build && npm run start
```

## Структура

| Путь | Назначение |
|------|-----------|
| `lib/detectors.js` | 7 детекторов нарушений — **ядро продукта** |
| `lib/fines.js` | Справочник штрафов по КоАП (реформа 30.05.2025) |
| `lib/templates.js` | Шаблоны 4 документов (заполнение болванок переменными) |
| `lib/docx.js` | Сборка DOCX из блоков шаблона |
| `app/api/scan/` | Сканер сайта |
| `app/api/generate/` | Генерация документа (`?doc=policy|consent|rkn|order`) |
| `app/api/monitor/` | Stub подписочного рескана |
| `app/page.jsx` | Лендинг с позиционированием и ценами |
| `app/scan/` | Страница отчёта |
| `app/documents/` | Визард + оплата + выгрузка |

## 7 детекторов

1. Политика обработки ПД — опубликована ли
2. Согласие у форм сбора данных
3. Зарубежные счётчики/сервисы (GA, FB Pixel, зарубежные CDN…)
4. Cookie-уведомление
5. Ссылка на политику/согласие рядом с формами
6. Уведомление в реестре операторов РКН (ручная проверка)
7. Локализация данных в РФ (эвристика по инфраструктуре)

Каждый пункт честно помечен: `нарушение` / `норма` / `ручная проверка`.

## Что доделать до прода (приоритет)

1. **Юрист.** Прогнать `lib/templates.js` через практикующего юриста по ПД — закрывает 90% риска.
2. **Оплата.** Заменить заглушку в `app/documents/Wizard.jsx` на ЮKassa/CloudPayments
   + вебхук подтверждения перед выдачей файлов (`app/api/generate`).
3. **БД на серверах в РФ.** Заказы, подписки, история сканов (Selectel/Timeweb/VK Cloud).
4. **Playwright** вместо `fetch` в `app/api/scan` — для сайтов с тяжёлым JS-рендерингом
   (детекторы уже принимают готовый контекст `{ url, html, $, bodyText }` — менять только загрузку).
5. **Мониторинг.** Крон (n8n) по списку подписчиков → сравнение с историей → email/телеграм-алерт.
6. **Сбор лида на сканере** — форма email/телефон перед показом отчёта (для ручной валидации спроса).

## ⚠️ Дисклеймер

Сервис — инструмент подготовки документов и выявления типовых нарушений.
Не является юридической консультацией. Суммы штрафов ориентировочные.
Документы требуют финальной вычитки.
